🕰️Clock

A simple, responsive  clock built using HTML, CSS, and JavaScript.

It dynamically updates every second and mimics the functionality of a real clock using DOM manipulation and CSS transforms.

-----

⚙️ Features
-Real-time hour, minute, and second hands
-Responsive design (works on desktop and mobile)
-Clean and minimal UI
-No external libraries or frameworks

------

🛠️ Built With
-HTML
-CSS
-JavaScript

-----
